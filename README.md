# EarnVerity Case Study

EarnVerity is a website I built to make it easier to compare apps and websites that offer ways to earn or save money. The site currently includes 72 platforms with information such as eligibility, payout timing, fees, categories, and important disclosures.

This repository shows some of the work behind the website, including how I organized the data, checked information, fixed issues, and improved the site over time.

## What I worked on

- Built and maintained a mobile-friendly directory with 72 earning and financial platforms.
- Organized platform information into structured fields so listings are easier to compare.
- Added search, filters, saved listings, dark mode, state availability, and platform detail pages.
- Improved navigation and page layout so the site is easier to use on desktop and mobile.
- Added SEO and indexing tools to help individual platform pages appear in search results.

## Data and quality checks

A large part of the project has been keeping the information organized and consistent. I regularly checked the site for:

- outdated or inconsistent information
- duplicate records
- broken or incorrect links
- missing platform details
- inconsistent labels and categories
- mobile layout problems
- unclear buttons or page states

When I found issues, I corrected the data or updated the page instead of only changing the visual design.

## Site improvements

As the site grew, some pages became too long and repeated the same information. I reviewed the existing content and simplified parts of the site so users could get to the useful information faster.

Some changes included:

- shortening repeated homepage content
- reorganizing navigation into clearer sections
- making platform information easier to scan
- improving contrast and readability
- fixing responsive layout problems
- cleaning up duplicated or outdated content

## Research and verification

I also worked on checking information before adding or updating a platform. This included reviewing official pages, payout details, eligibility rules, fees, and other restrictions when available.

For newer platforms, I sometimes contacted the company directly to clarify details instead of presenting uncertain information as verified.

## Testing

I tested pages across different screen sizes and checked common user actions such as:

- searching and filtering platforms
- opening platform detail pages
- saving listings
- following external links
- switching between light and dark mode
- using the site on mobile layouts

I also checked production changes after deployment to make sure fixes worked on the live site.
